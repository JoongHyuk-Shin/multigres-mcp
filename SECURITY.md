# Security policy

Report a vulnerability privately through this repository's Security tab ("Report a vulnerability") instead of opening a public issue.

A security issue is anything that breaks what the [Safety](README.md#safety) section of the README promises, for example a statement that the restricted mode accepts but that changes data, calls a function outside the allow list, or leaves session state for the next client of the gateway.

Fixes are released from `main` as a new version. Older versions are not patched.
